## 2. Mandatory Cost Guardrails (Enforced in IaC)

### 1. Zero-Cost Network Routing (No NAT Gateway)
- **Standard AWS Pattern:** A standard VPC NAT Gateway costs **$32.40/month** base fee plus $0.045/GB data processing.
- **CampusVoice Architecture:** Utilizes an **AWS Gateway VPC Endpoint for Amazon S3** attached directly to private route tables.
- **Cost:** **$0.00 / month** (100% free with unlimited internal bandwidth to S3 data lake).

### 2. Amazon Athena 100 MB Byte-Scan Cutoff
- Athena charges $5.00 per TB scanned.
- A dedicated analytics workgroup `campusvoice-analytics-dev` enforces:
  ```yaml
  BytesScannedCutoffPerQuery: 104857600  # 100 MB max per query
  EnforceWorkGroupConfiguration: true
  ```
- Any malformed or runaway analytical query is automatically cancelled before incurring measurable costs. In practice, partition-pruned queries scan only 5 KB to 20 KB per query.

### 3. Serverless Microservices vs. Always-On Clusters
- **Avoided Services:** Amazon OpenSearch Service ($18 - $35/mo), SageMaker Real-Time Endpoints ($45/mo), Provisioned EMR ($30/mo), RDS Aurora ($25/mo), Bedrock Knowledge Bases ($15/mo).
- **Alternative Implemented:**
  - In-memory pure-Python vector cosine similarity and dot product in AWS Lambda.
  - S3-backed vector cache (`vectors/<batch_id>.json`).
  - Snappy-compressed Parquet lake queried on-demand with Athena and Glue Data Catalog.

### 4. S3 Automated Lifecycle Expiration
- Query results generated by Athena in `s3://campusvoice-processed-*-dev/athena-results/` are configured with an automated S3 Lifecycle rule expiring and purging all results older than **7 days**.

### 5. Amazon Bedrock Token Optimization
- RAG and Agent inference calls are constrained to `maxTokens: 500`.
- System prompts are concise and grounded.
- ReAct Agent autonomous tool loops are capped at a strict maximum of **5 iterations** to prevent runaway token billing loops.
